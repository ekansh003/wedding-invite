## 💌 About the Project

**Anjali & Kunal — Wedding Invitation** is a thoughtfully designed digital wedding invitation that brings together elegant typography, delicate floral illustrations, warm ivory tones, antique gold accents, and a romantic visual experience.

Created with React and TypeScript, the website transforms a traditional wedding invitation into an interactive online experience that guests can access and share from anywhere.

The design draws inspiration from luxury wedding stationery, watercolor florals, and timeless Indian wedding aesthetics.

## ✨ Features

- **Interactive Wedding Cover** — A floral opening experience with an animated envelope and satin bow.
- **Elegant Invitation Design** — Romantic typography, watercolor illustrations, and a refined ivory, burgundy, and antique-gold palette.
- **Wedding Countdown** — A countdown to the special day.
- **Venue Details** — A dedicated section featuring the wedding venue and location information.
- **Wedding Schedule** — A timeline highlighting the celebrations, from the ring ceremony and lunch to the wedding ceremony, reception, and dinner.
- **A Note From Us** — A personal message presented in a beautifully styled section.
- **Floral Closing Section** — A decorative ending featuring the couple's names and wedding date.
- **Responsive Layout** — Designed to provide an enjoyable experience across desktop and mobile screens.
- **Social Sharing Metadata** — Open Graph and social preview metadata for sharing the invitation link.
- **Custom Favicon Support** — Website icon and mobile home-screen icon assets.
- **Automatic Deployment** — Hosted on Vercel with GitHub integration.

## 🎨 Design Philosophy

The website follows a romantic, elegant, and timeless design direction.

- **Warm Ivory:** Creates the feel of premium wedding stationery.
- **Antique Gold:** Adds delicate decorative details and a luxurious finish.
- **Burgundy:** Provides rich contrast and visual emphasis.
- **Floral Illustrations:** Introduce softness and a watercolor-inspired aesthetic.
- **Elegant Typography:** Combines expressive script lettering with readable serif typography.

The goal is to preserve the warmth of a traditional wedding invitation while presenting it through a modern digital experience.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm, which is included with Node.js
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/ekansh003/wedding-invite.git
```

### 2. Navigate to the Project Directory

```bash
cd wedding-invite
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```

### 5. Create a Production Build

To check whether the project builds successfully:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🌐 Live Deployment

The website is deployed using Vercel.

**Live Website:** https://anjali-kunal.vercel.app/

The project is connected to GitHub for version control and deployment updates.

To publish new changes:

```bash
git add .
git commit -m "Describe your changes"
git push
```

Vercel can automatically build and deploy the latest changes pushed to the connected repository.

## 📱 Social Sharing
